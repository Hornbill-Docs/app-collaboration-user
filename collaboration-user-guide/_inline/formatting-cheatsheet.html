Add a little formatting to any post, comment or conversation message — just type the markup as you write. Here are the everyday options.

Text

Type thisYou'll see
**bold**bold
''italic''italic
<del>strikethrough</del>strikethrough

Headings

Wrap a line in equals signs — fewer signs make a bigger heading.

Type thisYou'll see
=Big heading=a large heading
==Smaller heading==a smaller heading

Lists

Start each line with * for a bullet, or # for a number.

Type thisYou'll see
* Apples
* Oranges
  • Apples
  • Oranges
# First
# Second
  1. First
  2. Second

Links

Plain web addresses become links on their own — you only need this to give a link friendlier text.

Type thisYou'll see
[[https://hornbill.com|Our website]]Our website

Code

Wrap code in [code] … [/code] to keep its spacing and use a monospaced font.

[code]
status = 200
[/code]

Quote

Wrap text in [quote] … [/quote] to set it apart as a quotation.

Ship it.

Emoticons

Type these and they turn into emoji as you go.

Type thisYou'll see
:)😀
;)😉
:(😞
(y)👍  …and plenty more

A couple of shortcuts

Type @ to mention a colleague, or / to open the quick-command menu (code blocks, tables and more).
